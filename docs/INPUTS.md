# 输入与建模规则

基坑模板包含：使用说明、工程、钻孔数据、地层材料、材料、围护结构、支撑与垫层、施工阶段、水力方案、漏水段、初始水条件。保持表名与首行字段，数值不要使用公式。

- 单位：长度/标高/总水头 m，力 kN，时间和水力阻力 day。二维横坐标为沿剖面距离。
- 钻孔按统一层序填写层底标高，不是埋深。相邻层底可相等，表示零厚度；未知值不可留空或任意填零。首末钻孔需覆盖模型范围。不自动解释断层、透镜体和层位对应。
- 材料 `soil` / `plate` / `anchor` 必须提供所选本构需要的完整参数。演示刚度和渗透系数不能直接用于工程。
- 围护 `interface_material=AUTO` 按墙与插值地层交点切分，复制对应土层界面参数，另设水力属性；显式填写土体材料 ID 表示整墙自定义覆盖。
- `anchor` 为轴向支撑，可用于砼支撑的轴向理想化；不模拟弯曲、开裂。需要弯曲时使用相应 `beam`/`plate` 参数。预应力仅在首次安装时施加。
- 施工动作：`walls`、`dewater`、`excavate`、`support`、`wait`、`slab`。前序阶段必须先出现，阶段 ID 唯一。
- 四种计算类型：塑性、固结、安全分析、完全耦合渗流—变形。仅输入阶段历时；旧的速度字段有数值时拒绝迁移。
- 固结/完全耦合历时必须大于零。安全分析需独立 `wait` 阶段，沿用前序状态，不同时进行开挖/支撑/水条件改变。
- 自动孔压方式：塑性/固结使用稳态地下水流，安全分析沿用前序，完全耦合使用耦合孔压。自动选择仅为软件配置规则，不保证适合每个物理问题。

JSON 示例与 Excel 应生成等价配置；`pitbuilder/workbook_headers.json` 保存中英文表头映射。更改表结构前需更新解析和测试。
