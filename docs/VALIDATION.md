# 验证范围和限制

历史开发环境：Windows x64、PLAXIS 2D Ultimate 2024.1.0.1060，离线 Python 3.7（Shapely 2、Matplotlib 3.5）及匹配的 PLAXIS Python 3.8。历史已验证 CLI 自动启动、建模、保存和重开，含材料/阶段属性回读与分层界面检查；历史文件与会话信息不纳入公开版本。

本次发布检查记录见 `RELEASE_VALIDATION.json`（由本地准备流程生成）。离线单元测试或预览通过不等于本次重新完成 PLAXIS 实测，更不等于工程计算正确。

当前公开版不包含原生模型或计算结果；先前测试模型已按用户要求清理。公开模板从合成 demo.json 重新生成，与工作中的工程表分开。

尚未验证所有 PLAXIS 版本、语言、许可组合及 GUI 文件选择全过程。没有校准本构、持水曲线、井抽水能力或工程安全性。默认不划网格、不计算。复杂地质解释、真实井群接口和通用自定义水力曲线不在当前完整支持范围。

已知部署限制：默认安装路径保留开发机示例，必须按 INSTALL.md 配置。模板再生成脚本依赖 @oai/artifact-tool，仅在具备该工具的作者环境中验证；使用已提供的 XLSX 不需要它。
