# 发布前清单

本次仅做本地准备。不要把旁边的“本机使用包”上传：它包含用户工作模板。

1. 选择仓库名、所有者和维护者联系方式；确认有权以 MIT 授权全部贡献。当前版权主体使用集体称谓 PLAXIS Strata contributors，没有虚构真实姓名。
2. 配置 SECURITY.md 私密报告渠道，补充正式仓库链接。确认第三方和数据权属。
3. 运行两组离线单元测试和 `--validate-only`；根据需要在匹配 PLAXIS 环境另做原生建模实测。记录确切版本，不把历史实测当成本次结果。
4. 运行 `python tools/package_release.py --output ../public-source.zip`。脚本拒绝敏感类型和开发目录，生成清单及 SHA256 文件。
5. 解压检查：XLSX、CMD、源码依赖和中文路径；完整目录结构必须保留。核对 RELEASE_VALIDATION.json 与校验和。
6. 正式公开前只选择开源源码目录或其压缩包；不要把本地发布总目录整体上传。不要包含 PLAXIS、DLL、工程文件、运行日志、.env、虚拟环境或真实模板。
